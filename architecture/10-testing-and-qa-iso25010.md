# 10 Testing Protocols & Quality Assurance
## 1. Methodology
The system will undergo strict **Black-Box Testing** to evaluate functionality without peering into the internal code [cite: 6, 13]. 

## 2. ISO/IEC 25010 Evaluation Criteria
*   **Functional Suitability:** Ensure image attachments upload without throwing 500 errors, and that hybrid queue slip scanning accurately retrieves the correct ticket data [cite: 6].
*   **Usability:** UI/UX assessment of both React and Flutter interfaces via Likert-scale surveys distributed to 50 respondents (officials and residents) [cite: 5, 6].
*   **Reliability:** Ensure the system does not crash when multiple residents submit document requests or issue reports simultaneously [cite: 6].

## 3. Manual Validation Testing
*   Testing the manual validation workflow for document requests to ensure state changes correctly propagate to the analytics dashboard [cite: 1, 11].
