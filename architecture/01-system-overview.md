# 01 System Overview
## 1. Project Context & Objectives
Gridy is a comprehensive Web and Mobile-Based Barangay Information and Service Management System designed to transition local governance from fragmented, manual processes to a centralized digital ecosystem [cite: 1, 13]. 

Following the SDLC approach mandated by the capstone panel, the objectives are:
*   **Analyze:** Current information dissemination and manual queue practices [cite: 3, 13].
*   **Design:** A scalable architecture for web and mobile interfaces [cite: 3, 13].
*   **Develop:** Modules for announcements, hybrid queue management, issue reporting (with images), document requests, and notifications [cite: 3, 13].
*   **Test & Evaluate:** Utilize Black-Box testing and ISO/IEC 25010 standards (Functional Suitability, Usability, Reliability) [cite: 1, 3, 13].

## 2. High-Level Implementation Scope
*   **Web Portal (ReactJS):** Focused on administrative oversight, analytics, and request validation [cite: 11, 13].
*   **Mobile App (Flutter):** Focused on resident accessibility (requests, scanning, issue reporting) and urgent official monitoring [cite: 11, 13].
