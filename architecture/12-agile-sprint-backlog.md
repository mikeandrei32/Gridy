# 12 Agile Sprint Roadmap (Capstone 2)
## 1. Iterative Development Cycle
Following the Agile Scrum methodology [cite: 5], development is broken down into two-week sprints:

*   **Sprint 1: Architecture & Auth Base:** Initialize Git repos, set up PostgreSQL, Django DRF, JWT Auth, and user profiles [cite: 5].
*   **Sprint 2: Core API & Admin Dashboard:** Build React UI skeleton. Develop Django models/APIs for Announcements, Schedules, and specific service categories (aid, medical) [cite: 5].
*   **Sprint 3: The Mobile App Base:** Initialize Flutter. Build resident login, announcement viewing, and document request forms [cite: 5].
*   **Sprint 4: Media & Issue Reporting:** Integrate camera plugin in Flutter. Set up Cloudinary in Django. Build end-to-end image-backed issue reporting [cite: 5].
*   **Sprint 5: Queueing & Real-Time Sync:** Build React Live Queue dashboard. Implement Flutter QR scanning. Integrate Firebase FCM for real-time alerts [cite: 5].
*   **Sprint 6: Polish, Testing & Deployment:** Deploy to Render/Vercel. Execute Black-Box test cases. Finalize ISO/IEC 25010 evaluations with respondents [cite: 5].
